# FocusBoard

Небольшая Kanban-доска для личных задач. Проект создаётся итеративно как учебный frontend-проект для портфолио.

## Запуск

```bash
npm install
npm run server
npm run dev
```

Frontend работает на `http://localhost:5173`, а API — на `http://127.0.0.1:3001`.

## API-сервер

- `GET /health` — проверка доступности сервера;
- `GET /api/tasks` — список задач;
- `POST /api/tasks` — создание задачи;
- `PATCH /api/tasks/:id` — редактирование или перемещение;
- `DELETE /api/tasks/:id` — удаление задачи.

Данные сохраняются в SQLite. Файл локальной базы не попадает в Git.
