# FocusBoard

Небольшая Kanban-доска для личных задач. Проект создаётся итеративно как учебный frontend-проект для портфолио.

## Запуск

```bash
npm install
npm run dev
```

## План развития

- [x] Каркас React/Vite и адаптивная статичная доска
- [ ] Данные задач, отображение карточек и счётчики
- [ ] Добавление и редактирование задач
- [ ] Фильтрация, поиск и приоритеты
- [ ] Сохранение в localStorage
- [ ] Тесты, доступность и обработка ошибок
- [ ] Подключение mock/API-сервиса и финальная документация

## Стек

React, JavaScript, Vite, CSS. Позже: React Testing Library, MSW или небольшой API на Fastify.

## Что можно рассказать на собеседовании

Проект развивается через маленькие осмысленные коммиты: от статичного UI к состоянию, сохранению данных, тестам и интеграции API. Решения и ограничения фиксируются в Issues и PR.
