# FocusBoard

Kanban-доска для личных задач: React-интерфейс, Fastify API и SQLite. В публичном демо задачи сохраняются в браузере, а локально проект можно запустить с полноценным API.

**[Открыть демо](https://500efka500.github.io/FocusBoard/)** · **[Посмотреть код](https://github.com/500EFKA500/FocusBoard)**

## Что умеет

- создавать, редактировать, удалять и переносить задачи;
- искать задачи и фильтровать по приоритету;
- управлять задачей мышью или клавиатурой через доступный `select`;
- подстраиваться под светлую/тёмную тему браузера и запоминать выбор;
- сохранять данные в SQLite через Fastify API;
- запускаться в Docker и проверяться тестами.

## Стек

React · JavaScript · Vite · Fastify · SQLite · Vitest · Docker · GitHub Actions

## Запуск локально

```bash
npm install
npm run server
npm run dev
```

Открой `http://localhost:5173`. API будет работать на `http://127.0.0.1:3001`.

## Проверка

```bash
npm test
npm run build
```

## Для собеседования

Логику задач я вынес в кастомный React-хук, работу с сервером — в отдельный API-клиент. Fastify реализует CRUD, SQLite сохраняет задачи между перезапусками, а ключевые API/UI-сценарии покрыты тестами. Для production есть Docker-конфигурация, для публичного демо — GitHub Pages.
